# Mission-3---Prototype-Micro-interactions

# Project Title
Fitness Tracker App for Students

# Description
This project demonstrates interactive prototyping and micro-interactions for a Fitness Tracker App for Students. The prototype includes connected user flows, smart animate transitions, button states, and interactive navigation between screens to improve the user experience.

# Tools Used
- Figma
- Prototype Mode
- Smart Animate
- Components
- Variants
- Auto Layout

# Features
- Interactive Navigation
- Home to Workout Flow
- Workout to Progress Flow
- Smart Animate Transitions
- Hover States
- Active States
- Clickable Prototype
# Deliverables
- Connected User Flows
- 2 Smart Animate Transitions
- Button States (Normal, Hover, Active)
- Interactive Prototype
